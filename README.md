# ZERO FLOAT PANEL

Android app source project: black + neon blue floating utility panel.

## Features
- Overlay permission request and floating window service.
- Shizuku service detection and permission request.
- Movable floating panel.
- ESP/AIMBOT demonstration switches only (UI state; no game interaction).

## Build
Open this folder in Android Studio (Giraffe or newer), allow Gradle sync, then Build > Build Bundle(s) / APK(s) > Build APK(s).

Requirements: Android SDK Platform 35, JDK 17+, Gradle plugin 8.6.1. Shizuku must be installed and running for its permission integration to work.

Package: `com.zerofloat.panel`
